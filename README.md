# 🗺️ インベスト・アドベンチャー（Invest Adventure）

遊びながら投資の基本が学べる、教育用ブラウザゲームです。
100万円の仮想マネーから始めて、10年間の資産形成を体験します。

**▶ プレイ方法： `index.html` をブラウザで開くだけ**（インストール・ビルド不要、スマホでも遊べます）

## 🎮 ゲームの流れ

1. 毎年、市場のヒントになる「ニュース」が届く
2. 資産を6つの置き場所（日本株ファンド／米国株ファンド／世界債券ファンド／金／暗号資産／現金）に、合計100%になるように振り分ける
3. その年の市場が動き、結果と「学びポイント」が表示される
4. 毎年の積立（12万円）と、投資クイズの知識ボーナスで資産を育てていく
5. 途中で「必ず儲かる」という怪しい勧誘イベントも発生…どうするかはプレイヤー次第
6. 10年後の最終資産でランク（称号）が決まり、投資スタイル診断と学んだことのまとめが表示される

## 🎓 学べること

- 分散投資（「卵を1つのカゴに盛るな」）
- 複利の力と、長期・積立の効果
- 金利と債券価格の関係、インフレと現金の目減り
- 為替（円安・円高）が海外資産に与える影響
- 暗号資産など値動きの激しい資産との付き合い方
- 投資詐欺の見分け方（「元本保証＋高利回り」は危険信号）
- NISA、手数料（信託報酬）、ドルコスト平均法などのクイズ

## 🌐 GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成する（例：名前を `invest-adventure` にする。Public を選択）
2. このフォルダの中身（`index.html` / `README.md` / `LICENSE` / `.nojekyll`）をアップロードする
   - Web画面なら「Add file → Upload files」からドラッグ＆ドロップでもOK
   - コマンドラインなら下の「コマンドで公開する場合」を参照
3. リポジトリの **Settings → Pages** を開く
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main / (root)** にして Save
5. 数分待つと `https://<ユーザー名>.github.io/invest-adventure/` で公開される

### コマンドで公開する場合

```bash
# このフォルダの中で実行
git init
git add .
git commit -m "Initial commit: インベスト・アドベンチャー"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/invest-adventure.git
git push -u origin main
```

その後、上記の手順 3〜5（Settings → Pages）を行えば公開されます。

## 🛠️ 技術仕様

- HTML / CSS / JavaScript のみ（単一ファイル `index.html`、外部ライブラリ・通信なし）
- 値動きは「資産ごとの平均リターン＋ランダムなブレ＋その年のイベント効果」で生成
- イベント12種類、クイズ8問を収録。数値は各ファイル先頭のデータ定義を編集すれば自由にカスタマイズ可能
